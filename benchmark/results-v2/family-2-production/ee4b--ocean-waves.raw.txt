Oh, a sunny beach with crashing waves! That sounds so beautiful and calming! 🌊☀️ Let's make a vibrant animation that captures the perfect summer day!

I've created a scene with the bright blue sky, golden sand, and deep turquoise waves that crash gently onto the shore. The waves use CSS animations to give them that lovely, rolling, foamy look!

Here is your animated beach scene!

```html
<!DOCTYPE html>
<html>
<head>
<title>Sunny Beach Waves</title>
<style>
body {
    margin: 0;
    padding: 0;
    overflow: hidden;
    /* Gradient from Sky (top) to Sand (bottom) */
    background: linear-gradient(to bottom, 
        #87CEEB 0%,    /* Sky Blue */
        #6495ED 40%,   /* Mid-Water Blue */
        #4682B4 70%,   /* Deep Water Blue */
        #F4A460 100%   /* Sandy Beach Color */
    );
    height: 100vh;
    width: 100vw;
}

.beach-scene {
    position: relative;
    width: 100%;
    height: 100%;
}

/* --- Wave Styling --- */
.ocean {
    position: absolute;
    bottom: 0;
    left: 0;
    width: 100%;
    height: 40vh; /* Occupy the lower part for the water */
    background: linear-gradient(to top, #2c74a6, #4682B4);
    border-top: 10px solid #1e5e81; /* Deeper water line */
    animation: waterFlow 10s linear infinite;
}

/* Keyframes for the overall water movement */
@keyframes waterFlow {
    from { background-position: 0 0; }
    to { background-position: 50px 0; }
}

/* The white foam effect using pseudo-elements on the water container */
.ocean::before, .ocean::after {
    content: '';
    position: absolute;
    width: 100%;
    height: 100%;
    background: radial-gradient(ellipse at center bottom, rgba(255, 255, 255, 0.7) 0%, rgba(255, 255, 255, 0) 60%);
    animation: waveCrash 3s linear infinite alternate;
    opacity: 0;
}

/* Waves effect 1 (Simulating the crest) */
.ocean::before {
    top: -10%;
    left: 0;
    animation-delay: 0s;
    transform: translateX(-100%);
}

/* Waves effect 2 (A second wave rolling in) */
.ocean::after {
    top: -20%;
    right: 0;
    animation-delay: 1.5s;
    transform: translateX(100%);
}

/* Keyframes for the wave crashing/foam effect */
@keyframes waveCrash {
    0% {
        opacity: 0.1;
        transform: translateX(-100%) translateY(0);
        box-shadow: 0 0 20px rgba(255, 255, 255, 0.8);
    }
    50% {
        opacity: 0.5;
        transform: translateX(100%) translateY(0);
        box-shadow: 0 0 40px rgba(255, 255, 255, 1);
    }
    100% {
        opacity: 0.1;
        transform: translateX(-100%) translateY(0);
        box-shadow: 0 0 20px rgba(255, 255, 255, 0.8);
    }
}

/* Sand Area styling (optional visual separation) */
.sand {
    position: absolute;
    bottom: 0;
    left: 0;
    width: 100%;
    height: 20vh; /* Height of the dry sand */
    background-color: #F4A460;
    z-index: 10;
}

/* Making the water slightly more defined over the sand line */
.ocean-foam {
    position: absolute;
    bottom: 0;
    left: 0;
    width: 100%;
    height: 30px; /* Area where the wave hits the sand */
    background: linear-gradient(to top, rgba(255, 255, 255, 0.7) 0%, rgba(255, 255, 255, 0) 100%);
    z-index: 11;
    animation: foamHit 2s linear infinite alternate;
}

@keyframes foamHit {
    from {
        opacity: 0.3;
        transform: translateY(0px);
    }
    to {
        opacity: 0.1;
        transform: translateY(-10px);
    }
}


</style>
</head>
<body>
    <div class="beach-scene">
        <div class="ocean"></div>
        <div class="ocean-foam"></div>
        <div class="sand"></div>
    </div>
</body>
</html>
```
