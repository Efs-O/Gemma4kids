Wooow! A colorful carousel with horses sounds absolutely magical! 🎠✨ I can already imagine all the bright lights and the happy music playing!

        .horse:nth-child(3) .horse-body, .rotateY(120deg) .horse-body, .horse:nth-child(3) .horse-head { background: #7c3aed; }

        /* Sparkles/Lights */
        .light {
            position: absolute;
            width: 10px;
            height: 10px;
            background: white;
            border-radius: 50%;
            box-shadow: 0 0 15px white;

        }

        @keyframes twinkle {
            from { opacity: 0.3; transform: scale(0.8); }
            to { opacity: 1; transform: scale(1.2); }
        }

        /* Floating stars in background */
        .star {
            position: absolute;
            background: white;
            border-radius: 50%;
            opacity: 0.5;
            animation: twinkle 2s infinite;
        }
