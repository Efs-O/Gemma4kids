Wow, a spinning carousel with horses sounds like so much fun! What a wonderful, colorful idea for an animation! 🎠🐴✨

I'm going to use some bright colors and CSS animations to make the whole thing spin and look magical!

```html
<!DOCTYPE html>
<html>
<head>

<style>
    body {
        margin: 0;
        padding: 0;
        background: linear-gradient(to bottom, #ffecd1, #ffc8dd); /* Sunny carnival background */
        overflow: hidden;
        display: flex;
        justify-content: center;
        align-items: center;
        height: 100vh;
    }

    .carousel-container {
        width: 800px;
        height: 400px;
        position: relative;
        transform-style: preserve-3d;
        animation: spin 20s linear infinite; /* The main spinning animation */
        /* Setting the origin of the spin to the center bottom for a realistic carousel feel */
        transform-origin: center bottom;
    }

    @keyframes spin {
        from {
            transform: rotateY(0deg) translateZ(-100px);
        }
        to {
            transform: rotateY(360deg) translateZ(-100px);
        }
    }

    .horse {
        position: absolute;
        width: 120px;
        height: 180px;
        bottom: 0; /* Keeps them sitting on the "ground" */
        transform-origin: center bottom;
        animation: bounce 1s infinite alternate ease-in-out; /* Little bounce while spinning */
        /* Stagger the animations so they don't all bounce at the exact same time */
        animation-delay: calc(var(--delay) * 0.5s);
        /* Use 3D rotation to make them look like they are placed on a rotating platform */
        transform: rotateY(0deg) translateZ(0);
    }

    /* Keyframes for the continuous bounce */
    @keyframes bounce {
        from {
            transform: rotateY(0deg) translateZ(0) scale(1);
        }
        to {
            transform: rotateY(0deg) translateZ(0) scale(1.05);
        }
    }

    /* Styling the horses to look more detailed */
    .horse-body {
        width: 100%;
        height: 100%;
        background-color: #FF6347; /* Bright coral color */

    }

    .horse:nth-child(5) .horse-head { background-color: #C71585; }

</style>
</head>
```
