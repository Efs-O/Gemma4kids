Oh, that sounds like such a beautiful scene! Animated ocean waves on a sunny beach will look amazing! 🌊☀️

I can create a lovely animation using pure CSS to make the water roll in and crash right on the sand. I'll make sure the colors are bright and cheerful!

Here is the complete code for your animated beach scene:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ocean Waves Beach</title>
    <style>
        :root {
            /* Vivid Colors */
            --sky-color: #87CEEB; /* Bright Sky Blue */
            --deep-sea-color: #0077be; /* Medium Ocean Blue */
            --crashing-color: #1e90ff; /* Dodger Blue for waves */
            --sand-color: #f4a460; /* Sandy Brown/Orange */
            --sun-glow: #ffd700; /* Bright Gold */
        }

        body {
            margin: 0;
            padding: 0;
            overflow: hidden; /* Keeps the wave motion contained */
            background: linear-gradient(to bottom, var(--sky-color) 0%, #4682b4 60%, var(--sand-color) 100%);
            display: flex;
            flex-direction: column;
            height: 100vh;
            align-items: center;
        }

        /* --- Sky Area (Just for ambiance) --- */
        #sky {
            background: linear-gradient(to bottom, var(--sky-color) 0%, #4682b4 70%);
            height: 70vh;
            width: 100%;
            position: relative;
        }

        /* --- Sun --- */
        .sun {
            position: absolute;
            top: 10vh;
            left: 10vw;
            width: 120px;
            height: 120px;
            background: radial-gradient(circle, var(--sun-glow) 0%, rgba(255, 165, 0, 0.5) 50%, transparent 100%);
            border-radius: 50%;
            box-shadow: 0 0 50px 20px rgba(255, 215, 0, 0.8);
            z-index: 1;
        }

        /* --- Water Area --- */
        #water-container {
            position: absolute;
            bottom: 0;
            left: 0;
            width: 100%;
            height: 30vh; /* Defines the water height area */
            background-color: rgba(0, 123, 190, 0.8); /* Base deep water color */
            z-index: 10;
            overflow: hidden; /* Crucial: keeps the waves inside */
        }

        /* --- Wave Animation --- */
        .wave {
            position: absolute;
            width: 100%;
            height: 100%;
            top: 0;
            left: 0;
            background: radial-gradient(ellipse at center, rgba(255, 255, 255, 0.2) 0%, transparent 60%);
            animation: waveMove linear infinite;
            opacity: 0.8;
        }

        /* Multiple waves for complexity */
        .wave:nth-child(1) {
            transform: translateY(10px);
            animation-duration: 5s;
            animation-delay: 0s;
        }

        .wave:nth-child(2) {
            transform: translateY(30px);
            animation-duration: 6s;
            animation-delay: -1s;
            opacity: 0.9;
        }

        .wave:nth-child(3) {
            transform: translateY(50px);
            animation-duration: 7s;
            animation-delay: -2s;
            opacity: 0.7;
        }

        @keyframes waveMove {
            0% {
                transform: translateX(-100%) translateY(0);
            }
            100% {
                transform: translateX(100%) translateY(0);
            }
        }
        
        /* Special animation for the wave crest/crash effect */
        @keyframes waveCrest {
            0% {
                transform: scaleY(0.8) translateY(10px);
                opacity: 0.6;
            }
            50% {
                transform: scaleY(1.1) translateY(-5px);
                opacity: 1;
            }
            100% {
                transform: scaleY(0.8) translateY(10px);
                opacity: 0.4;
            }
        }

        /* Applying the crest animation specifically to simulate crashing */
        .crash-effect {
            position: absolute;
            bottom: 0;
            width: 100%;
            height: 15%;
            background: rgba(30, 144, 255, 0.8); /* Brighter blue for the crash */
            animation: waveCrest 2s linear infinite;
            animation-timing-function: ease-in-out;
            /* Staggering the crash timing */
        }
        
        .crash-effect:nth-child(1) {
            animation-delay: 0s;
        }
        .crash-effect:nth-child(2) {
            animation-delay: 1.5s;
        }
        .crash-effect:nth-child(3) {
            animation-delay: 3s;
        }


        /* --- Sand Area --- */
        #sand {
            flex-grow: 1; /* Takes up remaining space */
            background: linear-gradient(to top, var(--sand-color) 0%, rgba(255, 165, 0, 0.1) 100%);
            z-index: 5;
        }

    </style>
</head>
<body>
    <!-- Sky and Sun -->
    <div id="sky">
        <div class="sun"></div>
    </div>

    <!-- Water Container and Waves -->
    <div id="water-container">
        <!-- Base wave illusion layers -->
        <div class="wave"></div>
        <div class="wave"></div>
        <div class="wave"></div>
        
        <!-- Visible crash/foam effects -->
        <div class="crash-effect"></div>
        <div class="crash-effect"></div>
        <div class="crash-effect"></div>
    </div>

    <!-- Sand Area -->
    <div id="sand"></div>
</body>
</html>
```

I put the blue wave layers in the background to give the *idea* of the constant rolling ocean, and then I added the `.crash-effect` elements with a separate, more dramatic animation to simulate the actual *crash* foam on the sand! I also added a sunny glow in the sky!
